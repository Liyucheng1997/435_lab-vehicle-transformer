# AURORA-7 · 极光七号

一台能在浏览器里变形的原创机甲：钴蓝色 GT 跑车 ⇄ 约 6 米高的人形机甲。
全部模型用代码生成（Three.js 程序化建模），没有任何外部模型或贴图文件。

> 原创设计，与任何现有变形机器人作品的角色、标志无关。

## 运行

需要 Node.js 18 及以上。

Windows 下双击 `启动.bat` 即可（首次会自动安装依赖）。或者手动：

```bash
npm install
npm run dev
```

然后打开 http://localhost:5435 。

## 操作

| 操作 | 说明 |
|---|---|
| 变形 / 还原 | 点按钮或按空格，约 5.6 秒 |
| 进度条 | 拖动可停在任意中间状态 |
| 视角 | 主视角、正面、侧面、背面、特写；鼠标可自由拖动缩放 |
| 车漆 | 钴蓝、熔岩橙、翡翠绿、珍珠白、曜石黑 |
| 开关 | 自动环绕、灯光、音效 |

## 变形对应关系

| 载具部件 | 机甲部位 |
|---|---|
| 引擎盖（左右两半） | 胸甲，中间露出反应炉 |
| 前翼子板 + 前轮 | 肩甲 |
| 车门 | 背后的双翼 |
| 车头保险杠 | 胯部裙甲 |
| 车顶 + 后窗 | 背包 |
| 后半车身 + 后轮 | 小腿 |
| 车尾 | 脚后跟护板 |
| 门槛 | 前臂刃 |

头、躯干、大腿、手臂、手、脚是单独建模的机械结构，载具形态时收在车壳内部。

## 实现要点

- **车身**：一张参数化曲面（超椭圆截面沿车长放样）切成引擎盖、翼子板、车门等面板，每块带厚度和轮拱开口，所以面板之间严丝合缝。
- **变形**：每个部件记录"载具姿态"和"机甲姿态"两套变换，按各自的时间窗插值；每帧把最低点贴到地面，所以车是以车尾为支点立起来的。
- **渲染**：PBR 金属漆 + 清漆层、烘焙的摄影棚环境光、镜面地面、环境光遮蔽、辉光。
- **音效**：伺服声和金属撞击声由 WebAudio 实时合成。
